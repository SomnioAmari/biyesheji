# 功能测试文档

> 项目：可配置内容源聚合与纯净阅读系统
> 测试类型：功能测试（黑盒测试）

---

## 1. 概述

### 1.1 测试目的

验证系统各功能模块是否按需求正确实现，检查主要业务流程（注册登录、新闻抓取、书籍上传审核、书源搜索、章节阅读、阅读增强）能否正常运行，发现并修复功能缺陷。

### 1.2 测试范围

覆盖认证与权限、新闻源管理、新闻抓取与展示、文章阅读与收藏、书源管理、书籍上传审核、内部书库与书源搜索、书架、阅读进度、阅读设置与朗读、管理员功能共 11 个模块。

## 5. 测试结果分析

共设计并执行 44 个测试用例，全部通过。测试过程中发现并修复了以下问题：

1. **新闻抓取"入库 0 条"**：文章表按 URL 全局去重，两个账号订阅同一源时后抓取的账号全部被判重复。将唯一键改为「来源编号 + URL 哈希」后解决。
2. **书籍上传"章节链接不能为空"**：上传书籍的章节没有外部链接，但章节表的链接字段不允许为空。将字段改为可空后解决。
3. **章节拆分空章节**：部分 TXT 在开头罗列目录，导致拆分出大量空章节。拆分后增加空章节过滤，并兼容带空格标题、书名前缀标题，避免"前言后语"误判。
4. **书源章节只抓第一页**：部分站点把长章节拆成多页。增加"下一页"链接选择器与同一章节判断，自动拼接完整正文。
5. **书源名乱码**：历史导入时中文名编码出错显示为问号，已修正数据。
