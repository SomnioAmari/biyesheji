# 接口设计文档

> 项目：可配置内容源聚合与纯净阅读系统
> 风格：RESTful，统一前缀 `/api`，数据格式 JSON

---

## 1. 概述

前后端通过 HTTP 接口通信，后端统一返回 JSON。除注册、登录外，所有接口需在请求头携带 `Authorization: Bearer <token>`。管理员接口还需校验当前用户角色为管理员。

## 2. 通用约定

### 2.1 基础信息

- 后端地址：`http://localhost:8080`（前端开发服务器代理 `/api`）
- 数据格式：`application/json`（上传接口为 `multipart/form-data`）
- 编码：UTF-8

### 2.2 统一返回结构

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

- `code`：状态码，200 表示成功。
- `message`：提示信息。
- `data`：业务数据，无数据时为 null。

### 2.3 状态码

| 状态码 | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数错误 / 业务错误 |
| 401 | 未登录或登录过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 系统错误 |

### 2.4 鉴权流程

请求进入 `AuthInterceptor` 拦截器，解析令牌得到用户编号后查库获取最新角色与状态；状态为禁用则返回 403，角色非管理员访问 `/api/admin/**` 接口同样返回 403。

## 3. 接口详细说明

### 3.1 认证模块

**POST /api/auth/register** —— 用户注册

- 请求体：`{ "username": "xxx", "password": "xxx", "nickname": "xxx", "email": "xxx" }`
- 返回：`UserVO`（用户信息）
- 说明：用户名唯一，密码 BCrypt 加密，默认注册为普通用户。

**POST /api/auth/login** —— 登录

- 请求体：`{ "username": "xxx", "password": "xxx" }`
- 返回：`{ "token": "JWT", "user": { ... } }`
- 说明：签发 7 天有效期 JWT。

### 3.2 新闻源模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/news-sources | 查询当前用户新闻源列表 |
| POST | /api/news-sources | 新增新闻源 |
| PUT | /api/news-sources/{id} | 编辑新闻源 |
| DELETE | /api/news-sources/{id} | 删除新闻源 |
| POST | /api/news-sources/{id}/fetch | 立即抓取该源 |

新闻源请求体字段：`type`（0 RSS / 1 网页）、`name`、`url`、`category`、`ruleJson`、`weight`、`fetchInterval`、`enabled`。

抓取接口返回 `FetchLog`（`status`、`fetchedCount`、`message`）。

### 3.3 文章模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/articles | 主页资讯流（参数 page、size、sourceId） |
| GET | /api/articles/favorites | 收藏的文章列表 |
| GET | /api/articles/{id} | 文章详情（正文、收藏状态、阅读进度） |
| POST | /api/articles/{id}/favorite | 收藏文章 |
| DELETE | /api/articles/{id}/favorite | 取消收藏 |

资讯流返回 `{ total, list }`，list 为 `ArticleVO`（标题、来源、摘要、时间、是否收藏）。

### 3.4 书源模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/book-sources | 查询当前用户书源列表 |
| POST | /api/book-sources | 新增书源 |
| PUT | /api/book-sources/{id} | 编辑书源 |
| DELETE | /api/book-sources/{id} | 删除书源 |
| POST | /api/book-sources/import | 粘贴导入书源（legado/本系统格式） |
| POST | /api/book-sources/import-url | URL 导入书源 |
| POST | /api/book-sources/reconvert | 原地重转换已导入规则 |

书源请求体字段：`name`、`url`、`ruleJson`、`enabled`。导入接口请求体：`{ "ruleJson": "..." }` 或 `{ "url": "..." }`，支持单个或合集数组。

### 3.5 书籍模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/novel/search | 内部书库搜索（参数 keyword） |
| GET | /api/novel/search-sources | 书源搜索（参数 keyword） |
| POST | /api/novel/upload | 上传书籍（multipart） |
| GET | /api/novel/mine | 我的上传作品列表 |
| DELETE | /api/novel/mine/{id} | 删除我的上传作品 |
| GET | /api/novel/detail | 书源书籍详情（参数 sourceId、bookUrl） |
| GET | /api/novel/{bookId} | 书籍详情 |
| GET | /api/novel/{bookId}/catalog | 章节目录 |
| GET | /api/novel/{bookId}/{chapterId} | 章节正文 |

上传接口（multipart）字段：`title`（必填）、`author`、`category`、`intro`、`cover`（图片文件）、`file`（TXT 文件）、`content`（粘贴全文，与 file 二选一）。

内部书库搜索返回 `LibraryBookVO`（bookId、书名、作者、封面、简介、分类、章节数）；书源搜索返回 `SearchBookVO`（sourceId、sourceName、书名、作者、封面、详情链接）。

### 3.6 书架模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/bookshelf | 书架列表 |
| POST | /api/bookshelf/{bookId} | 加入书架 |
| DELETE | /api/bookshelf/{bookId} | 移出书架 |

书架列表返回 `BookshelfVO`（bookId、书名、作者、封面、章节数、最后阅读章节）。

### 3.7 进度模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/progress | 查询进度（参数 targetType、targetId） |
| PUT | /api/progress | 上报进度 |

进度请求体：`{ "targetType": 0/1, "targetId": ..., "chapterId": ..., "scrollPosition": 0~1 }`。

### 3.8 管理模块

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/admin/users | 用户分页列表（参数 keyword、page、size） |
| PUT | /api/admin/users/{id}/status | 启用/禁用用户 |
| PUT | /api/admin/users/{id}/role | 设为/取消管理员 |
| PUT | /api/admin/users/{id}/password | 重置密码 |
| GET | /api/admin/novels | 书籍审核列表（参数 reviewStatus、keyword、page、size） |
| POST | /api/admin/novels/{bookId}/review | 审核（通过/驳回） |
| DELETE | /api/admin/novels/{bookId} | 删除书籍 |

审核请求体：`{ "approved": true/false, "reason": "驳回原因" }`。

---

## 4. 错误处理

业务异常统一由 `GlobalExceptionHandler` 捕获，返回 `{ code, message }`。常见业务错误直接抛出 `BizException`（可带自定义状态码与提示信息），参数校验错误返回 400，系统异常返回 500 并记录日志。
