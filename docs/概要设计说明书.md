# 概要设计说明书

## 基于 Spring Boot 的可配置内容源聚合与纯净阅读系统

---

## 1. 引言

本文档给出系统的总体架构、技术选型、模块划分、数据库设计与接口设计，是详细设计与编码实现的依据。

## 2. 总体架构

系统采用**前后端分离 + 单体后端**架构：

```
┌──────────────────────────────────────────────┐
│                浏览器 (Vue 3)                  │
│  登录 │ 资讯流 │ 文章 │ 新闻源 │ 搜索 │ 书架 │ 章节 │ 书源 │
└──────────────────────┬───────────────────────┘
                       │ HTTP/JSON (JWT)
┌──────────────────────▼───────────────────────┐
│              Nginx（静态托管 + 反向代理 /api）  │
└──────────────────────┬───────────────────────┘
                       │
┌──────────────────────▼───────────────────────┐
│            Spring Boot 后端（单体）            │
│  Controller ─ Service ─ Mapper（MyBatis）      │
│  通用组件：HTTP抓取 · Jsoup清洗 · 规则引擎 · 调度│
└──────────┬────────────────────┬───────────────┘
           │                    │
     ┌─────▼─────┐        ┌─────▼─────┐
     │  MySQL 8  │        │   Redis   │
     │ 持久化存储 │        │ 新闻缓存  │
     └───────────┘        └───────────┘
```

**设计要点**：
- 新闻板块"定时拉取 + 缓存 + 个性化"；小说板块"书源规则 + 搜索 + 书架"；两者逻辑独立，复用底层抓取/解析/清洗组件。
- 正文清洗在后端入库前完成，前端只展示干净 HTML，从架构上避免广告进入阅读页。

## 3. 技术选型

| 层 | 技术 | 说明 |
| --- | --- | --- |
| 后端框架 | Spring Boot 3.5 | 单体、快速搭建 |
| 持久层 | MyBatis | 注解 + `<script>` 动态 SQL |
| 数据库 | MySQL 8 | 事务、去重唯一索引 |
| 缓存 | Redis | 主页候选集 ZSET，降级回源 MySQL |
| 认证 | JWT（jjwt）+ BCrypt | 无状态认证 |
| HTML 解析 | Jsoup | CSS/XPath 选择器、正文清洗 |
| 定时任务 | Spring @Scheduled | 定时批量抓取 |
| HTTP 客户端 | Java HttpClient（HTTP/1.1） | 抓取外部源，支持 GET/POST、自定义头 |
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router + Axios | SPA |
| 部署 | Nginx | 静态托管 + 反向代理 |

## 4. 模块划分

后端包结构（`com.reader`）：

```
config       Web/CORS 配置
controller   Auth / NewsSource / Article / BookSource / Novel / Bookshelf / Progress
service      Auth / NewsSource / NewsFetch / NewsCache / Rank / Article / Novel / BookSource / Progress
mapper       User / NewsSource / Article / BookSource / NovelBook / NovelChapter / Bookshelf / ArticleFavorite / ReadingProgress / UserBehavior / FetchLog
entity/dto/vo  实体、请求、视图对象
parse        HttpFetcher（HTTP抓取）、RssParser（RSS解析）、HtmlCleaner（正文清洗）
rule         BookSourceRule（规则模型）、RuleEngine（规则引擎）、LegadoRuleConverter（legado转换）
scheduler    NewsFetchScheduler（定时抓取）
common       Result / ResultCode / BizException / GlobalExceptionHandler / JwtUtil / UserContext / AuthInterceptor / PageResult
```

**职责划分**：

| 模块 | 职责 |
| --- | --- |
| 认证 | 注册登录、JWT 签发与校验、BCrypt 加密、拦截器鉴权 |
| 新闻源 | 新闻源 CRUD、启停、权重/频率 |
| 抓取 | RSS/网页源抓取、正文清洗、幂等入库、刷新缓存、抓取日志 |
| 缓存 | Redis 候选集维护（ZSET，member=articleId，score=发布时间） |
| 排序 | 源权重 + 时间衰减 + 行为分 |
| 文章 | 资讯流分页、详情、收藏 |
| 书源 | 书源 CRUD、粘贴/URL 导入、legado 格式转换、原地重转换 |
| 规则引擎 | 搜索/详情/目录/正文四环节，CSS/XPath + POST + 提取方式 |
| 小说 | 搜索、详情、目录、章节、书架 |
| 进度 | 文章滚动百分比、小说章节 |

## 5. 数据库设计

共 11 张表：user、news_source、article、book_source、novel_book、novel_chapter、bookshelf、article_favorite、reading_progress、user_behavior、fetch_log。

### 5.1 表清单

| 表 | 说明 | 关键约束 |
| --- | --- | --- |
| user | 用户 | username 唯一 |
| news_source | 新闻源 | type: 0=RSS 1=网页源 |
| article | 新闻文章 | url_hash 唯一（去重），published_at 索引 |
| book_source | 小说书源 | rule_json 存规则 |
| novel_book | 小说书 | 存详情页 url、目录 url |
| novel_chapter | 章节 | (book_id) 索引，按 chapter_index 排序 |
| bookshelf | 书架 | (user_id, book_id) 唯一 |
| article_favorite | 文章收藏 | (user_id, article_id) 唯一 |
| reading_progress | 阅读进度 | (user_id, target_type, target_id) 唯一 |
| user_behavior | 行为 | (user_id, target_type, target_id) 唯一 |
| fetch_log | 抓取日志 | 记录源、状态、条数、时间 |

### 5.2 关键设计说明

- **去重**：`article.url_hash = SHA-256(规范化url)`，唯一索引防止重复入库。
- **通用进度**：`reading_progress` 用 `target_type` 区分文章（0）与小说（1），文章记 `scroll_position`，小说记 `chapter_id`。
- **通用行为**：`user_behavior` 记录点击与读完，供新闻个性化排序。
- **书架与收藏分离**：小说用 `bookshelf`，文章用 `article_favorite`。

> 完整 DDL 见 `sql/schema.sql`。

## 7. 部署架构

```
浏览器 ──> Nginx :80
              ├── /  → 前端静态资源（frontend/dist）
              └── /api/ → 反向代理 http://127.0.0.1:8080
```

- 后端 `java -jar pure-reader-backend-1.0.0.jar`，端口 8080
- 环境变量：`DB_USERNAME`、`DB_PASSWORD`、`REDIS_HOST`、`REDIS_PORT`、`JWT_SECRET`
- 抓取配置：`app.fetch.timeout-seconds`、`app.fetch.trust-all-certs`、`app.rank.*`

## 8. 安全设计

- 密码 BCrypt 加密存储
- JWT 无状态鉴权，拦截器校验，`UserContext` 线程变量传递用户
- 个人数据查询均按 `user_id` 过滤（防越权）
- 前端渲染正文走白名单（后端已清洗），防 XSS
- 证书信任开关默认关闭（`trust-all-certs: false`），按需开启
