# 真实内容源清单

> 本文件整理了**已实测可用**的新闻源（RSS）与书源，并给出「设置页一键导入」的说明。
> 内容源可用性受网络、站点反爬、限流等影响，失效后可自行编辑或重新导入。

## 二、书源（已实测搜索 / 详情 / 目录）

在「设置 → 书源」点 **「导入推荐书源」** 一键导入。两个书源是同一套 CMS（第八中文网同款）：

| 名称 | 首页 | 说明 |
| --- | --- | --- |
| 第八中文网 | `https://www.d8zw.com` | 实测搜索「遮天」返回 178 条，详情/目录正常 |
| 新笔趣阁 | `https://www.xbiquge.info` | 第八中文网同款镜像，规则一致 |

规则 JSON（以第八中文网为例）：

```json
{
  "name": "第八中文网",
  "url": "https://www.d8zw.com",
  "charset": "UTF-8",
  "searchUrl": "/search.php?q={{key}}",
  "searchList": "div.box dl",
  "searchName": "dt a img",
  "searchNameType": "alt",
  "searchAuthor": "dd.book_other span",
  "searchCover": "dt a img",
  "searchDetail": "dt a",
  "bookUrlPattern": "/(\\d+)/?$",
  "detailName": "h1",
  "detailAuthor": ".options ul li a",
  "detailCover": ".img-thumbnail",
  "detailIntro": "#intro_pc",
  "tocUrl": "{{bookUrl}}",
  "catalogList": ".book_list2 ul li",
  "catalogName": "a",
  "catalogUrl": "a",
  "contentUrl": "{{chapterUrl}}",
  "bookContent": "article",
  "contentNextPage": "a#next"
}
```

### 已知局限（免费书源共性）

1. **站点偶发 502**：抓取失败时重试即可。
2. **目录分页**：目录每页约 100 章，规则引擎只抓第一页（前 100 章），足够演示。
3. **热门书正文有字体反爬**：像《遮天》这类头部书，正文会被站点用「字体替换」加密，抓下来是乱码；冷门书正文正常。这是笔趣阁系站点对热门书的普遍做法，无法用规则规避。

> 章节内的正文分页（如「第(1/3)页」）已由规则引擎自动拼接，`contentNextPage` 选择器负责找到「下一页」链接，正文会被完整抓取。

## 三、导入步骤小结

1. **新闻源**：设置 → 新闻源 → 点「添加推荐源」。
2. **书源**：设置 → 书源 → 点「导入推荐书源」→ 到「书籍搜索」搜书名验证。
