### 使用建议

- **抓取频率**建议设 30～60 分钟；**源权重**可按关注程度设 1～10。
- 部分源可能因网络/反爬不可达，新增后用「立即抓取」验证。
- 若目标站点没有 RSS，可用"网页源"类型 + 列表/详情选择器规则。

## 二、小说书源

在「书源管理」页用「粘贴导入」或「URL 导入」导入下面 JSON。

### 2.1 笔趣阁365（已验证搜索 + 详情）

> 实测：搜索、详情正常；目录页因 Cloudflare 对非浏览器客户端限速可能较慢。
> 规则文件见 `docs/笔趣阁365书源.json`，也可直接粘贴：

```json
{
  "name": "笔趣阁365",
  "url": "https://www.biquge365.net",
  "charset": "UTF-8",
  "headers": { "Referer": "https://www.biquge365.net/" },
  "searchUrl": "/s.php",
  "searchMethod": "POST",
  "searchBody": "s={{key}}&type=articlename",
  "searchList": "ul.search li:not(.fen)",
  "searchName": "span.name a",
  "searchAuthor": "span.zuo a",
  "searchDetail": "span.name a",
  "bookUrlPattern": "/book/(\\d+)/",
  "detailName": "h1",
  "detailAuthor": ".xinxi .x1 a",
  "detailCover": ".zhutu img",
  "detailIntro": ".x3",
  "tocUrl": "/newbook/{{bookId}}/",
  "catalogList": "ul.info li",
  "catalogName": "a",
  "catalogUrl": "a",
  "contentUrl": "{{chapterUrl}}",
  "bookContent": ".txt"
}
```

### 2.3 如何自己写新书源

按 `docs/如何写书源与反爬.md` 的 F12 六步法，找无反爬的简单小说站手写规则即可。核心字段语义见 `docs/书源规则规范.md`。

## 三、导入步骤小结

1. **新闻源**：新闻源页 → 新增 → 类型 RSS → 填名称与 URL → 保存 → 立即抓取。
2. **书源**：书源管理页 → 粘贴导入（或 URL 导入）→ 粘贴上述 JSON → 导入 → 到小说搜索页搜索验证。
